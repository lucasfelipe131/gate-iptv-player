# Publicação do GATE TV

Este diretório reúne o material operacional para publicar o mesmo produto em duas lojas diferentes:

- `google-play/`: ficha, segurança de dados, acesso do revisor e checklist do Android/Google TV.
- `lg/`: ficha, cenário de UX e checklist preliminar do LG Seller Lounge.

## Regra de conformidade

O GATE TV é um player independente. A publicação não deve incluir listas, canais, filmes ou credenciais de terceiros. O usuário adiciona somente fontes próprias ou devidamente autorizadas.

## Monetização

A publicidade paga fica desativada enquanto `VAST_AD_TAG_URL` não contiver uma tag HTTPS aprovada. O arquivo público `app-ads.txt` deve receber apenas linhas fornecidas pelo parceiro publicitário contratado; identificadores de teste ou vendedores não autorizados não devem ser publicados.
