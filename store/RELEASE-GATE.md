# Critério de liberação

Uma versão só pode ser enviada às lojas quando:

- testes Node passam;
- Android lint e build passam;
- APK/AAB contém ARM64 e atende alinhamento de 16 KB;
- IPK LG é gerado pelo workflow aprovado;
- política de privacidade e suporte estão acessíveis por HTTPS;
- lista de demonstração funciona;
- ficha não promete conteúdo fornecido pelo GATE;
- anúncios falham de forma segura;
- tag VAST e app-ads.txt, quando ativos, pertencem ao parceiro aprovado;
- screenshots representam a interface real do commit submetido.
