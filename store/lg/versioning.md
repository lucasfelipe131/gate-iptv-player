# Versionamento webOS

- O ID `com.gateone.app.gateiptvplayer` deve permanecer estável.
- O campo `version` de `appinfo.json` deve aumentar em toda atualização enviada.
- O IPK precisa ser gerado a partir do mesmo commit aprovado nos testes.
- Alterações de permissões, APIs webOS ou comportamento publicitário devem ser descritas na nova submissão.
